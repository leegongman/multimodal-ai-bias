# 프로젝트 규칙

이미지·텍스트 QA 평가 파이프라인의 운영 기준

## 문제 정의

이미지와 텍스트를 함께 이해하는 멀티모달 모델을 사용해 각 질문의 선택지 인덱스를 예측하는 작업
사회적 단서가 포함된 문항에서 시각적·텍스트적 근거를 우선하고 불확실한 경우 보수적으로 판단하는 원칙

## 출력 계약

- 선택지 인덱스: `0`, `1`, `2`
- 최종 파일 컬럼: `sample_id`, `label`
- 행 순서: 입력 순서 유지
- 누락·중복·허용 범위 외 라벨: 생성 단계에서 거부

## 구현 원칙

1. 데이터 로딩, 모델 어댑터, 추론, 파싱, 검증, 결과 생성을 모듈별로 분리
2. 원본 모델 응답과 파싱 결과를 구분해 기록
3. 프롬프트 변경과 모델 변경을 같은 실험에서 동시에 수행하지 않음
4. 외부 API·비공개 데이터·하드코딩 정답 목록을 실행 경로에서 배제
5. 실행 환경, 모델 revision, 설정 checksum을 재현성 기록에 포함

## 공개 범위

코드·테스트·예시 설정·문서 공개
원본 데이터·가중치·개인 검수 자료·인증 정보 비공개
외부 자료는 출처와 라이선스만 기록

## 운영 상태

핵심 추론·파싱·검증 모듈 구현 완료
오프라인 회귀 테스트 구성
GPU 실행은 환경별 번들 및 기록 기준
독립 검수와 최종 기준셋 확정은 추가 확인 대상
