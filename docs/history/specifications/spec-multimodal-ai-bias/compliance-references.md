# Compliance References

## Competition Rules That Bend Design

| area | requirement |
|---|---|
| language | Competition code must use Python. |
| model cutoff | Only open-source model weights officially public by 2026-05-31 are allowed. |
| API ban | Remote model APIs are forbidden, including OpenAI API, Gemini API, Hugging Face Inference API, Together AI, and OpenRouter. |
| model execution | Inference must load weights on a participant-controlled PC, cloud server, or research server. |
| final answer | Final answers must be generated by an LLM, not pure rules, fixed answer lists, deterministic mapping, or simple majority vote. |
| external data | Public, self-collected, synthetic, and generative-AI-created data may be used if legal and license-safe. |
| leakage | Do not use evaluation-set question types, choice patterns, wording, constructions, or inferred answers to create training data, prompts, examples, or rules. |
| evaluation use | Evaluation data is inference-only. |
| output | CSV files must be UTF-8 and use `sample_id,label`. |
| submission limit | Maximum 5 submissions per day. |
| reference environment | RTX A6000 48GB, Python 3.10, CUDA 12.4, PyTorch 2.6.0, Ubuntu 20.04. |
| timing guidance | About 0.5 seconds/sample; about 70 minutes for 8,500 test rows; about 13 minutes for 1,500 Hidden rows. |

## Second-Round Readiness

If selected for second-round evaluation, the artifact set must support Private score reproduction and Hidden evaluation. Required readiness:

- separated train and inference code
- `.py` or `.ipynb` code files
- model files or documented model acquisition path
- all external data files used
- UTF-8 code and comments
- error-free library loading
- OS and library version record
- solution PDF suitable for a 15-minute presentation
- student-status evidence for all team members

## Compliance Ledger Fields

Every candidate must record:

- model name
- model revision or checkpoint id
- release/publication evidence for cutoff date
- license
- download/source URL
- remote API usage: must be `none`
- external data list and licenses
- whether train/test data was used only as allowed
- inference command
- environment hash or package list
- Reasoner/Verifier prompt versions and SHA-256 hashes
- parsed/verification schema versions and uncertainty option-index semantics version
- unresolved count and whether arbitration was used
- selected submission file

Before full 8,500-row production inference, the selected candidate must pass the target-environment, exact-snapshot/license, data/image, prompt/schema, real-image output, diagnostic failure, peak-VRAM/runtime, persistent artifact, submission validation, and network-disabled smoke gates. Only a 10/10 result may publish `GPU_SUBMISSION_READY`, and the operator must be notified before production starts.
