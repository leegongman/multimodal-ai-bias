# 평가 기준

공개된 안내 자료를 바탕으로 정리한 실행·공개 기준

## 입력과 출력

| 항목 | 기준 |
|---|---|
| 입력 | 이미지 경로, 문맥, 질문, 세 개 선택지 |
| 출력 | `sample_id`, `label` |
| 라벨 | 선택지 인덱스 `0`, `1`, `2` |
| 핵심 지표 | Balanced Accuracy |
| 실행 언어 | Python |
| 처리 방식 | 오프라인 모델 추론 |

## 저장소 적용 기준

1. 입력 원본은 저장소에 포함하지 않고 취득 절차와 파일 형식만 기록
2. 모델 가중치는 저장소에 포함하지 않고 모델 ID·revision·라이선스만 기록
3. 실행 코드와 환경 정보는 재현 가능한 형태로 공개
4. 원격 접속 정보, 인증 정보, 개인 식별 정보는 공개 전 제거
5. 결과 파일은 원본 정답이나 민감한 행 단위 자료가 없는 경우에만 선별 공개

## 실행 기록 기준

- Python·CUDA·PyTorch·추론 런타임 버전 기록
- 모델명과 가중치 revision 기록
- 데이터 준비부터 결과 생성까지의 명령 기록
- 입력·출력 파일 checksum 기록
- 실패 샘플과 파싱 오류 통계 기록

## 주의사항

공식 원문과 모델·데이터 라이선스는 공개 또는 실행 시점에 재확인 대상
이 문서는 프로젝트 정리용 요약이며 법률 자문이나 사용 허가의 대체물이 아님
