# 데이터 공개 정책

GitHub 공개 범위와 로컬 보관 기준

## 공개 대상

- 재현 가능한 Python 코드
- 실행 스크립트와 예시 설정
- 단위·계약 테스트
- 데이터 레이아웃 검증 로직
- 모델·데이터 출처 및 취득 절차 문서
- 개인 식별 정보와 비밀값을 제거한 실험 요약

## 제외 대상

| 대상 | 보관 위치 | 제외 사유 |
|---|---|---|
| 원본 이미지·CSV | `data/raw/` | 이용 조건·용량·재배포 제한 |
| 모델 가중치 | `models/snapshots/` | 용량·라이선스 |
| 대용량 실행 결과 | `runs/` | 저장소 용량·재현성 저하 |
| 제출 산출물 | `submissions/` | 결과 데이터와 공개 범위 검토 필요 |
| 인증 정보·원격 접속 정보 | 로컬 비추적 파일 | 보안 위험 |
| 개인 검수 원본 | 로컬 전용 영역 | 개인정보·검수 무결성 |

## 로컬 디렉터리 계약

```text
data/raw/open/        입력 자료 배치 위치
data/local-validation/검증용 로컬 자료
models/snapshots/     모델 가중치 배치 위치
runs/                 실행 로그와 중간 산출물
submissions/          최종 결과 파일
```

각 로컬 자료는 저장소에 포함하지 않고 `.gitignore` 기준으로 관리
필요한 자료는 파일 자체가 아닌 출처, 라이선스, 버전, checksum, 취득 절차만 문서화

## 공개 전 확인

1. 비밀키·토큰·비밀번호·IP·사용자명 제거
2. 원본 데이터와 모델 가중치 제외 확인
3. 결과 파일에 원본 정답 또는 개인정보 포함 여부 확인
4. 외부 라이선스와 재배포 조건 확인
5. 문서 링크와 실행 명령 검증
